# Manning Live Project -Building an E-commerce Web Application with Spring Boot

See: https://liveproject.manning.com/project/142/24/building-an-e-commerce-web-application-with-spring-boot?

## Milestone #1
- Created the initial Spring Boot project using Spring Initializr with the following dependencies:
  - **Spring Web**
  - **Spring Dev Tools**
  - **Mustache**
- Created the initial project structure with the following packages:
  - `com.example.ecommerce.controller`
- Added *.mustache files
  - Added index.mustache (main page)
    - layout/
      - header.mustache
      - footer.mustache
      - products.mustache
- Added test cases to check:
  - Each *.mustache file is rendered correctly
  - The controller returns the correct view name for "/"
- Used **Bootstrap** for styling the main page and the product list.

Milestone took 5 days to complete. I had to learn Mustache and Bootstrap to complete the milestone.
